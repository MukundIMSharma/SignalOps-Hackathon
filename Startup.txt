What each file holds

CLAUDE.md: the section 14 shared AI instructions, the task template, the stack, and the repo layout. Add rules like these:
Read docs/PROGRESS.md and docs/CONTRACTS.md before starting.
After each task, update PROGRESS.md.
Record any schema or tool change in CONTRACTS.md.
Never mark something done without running its tests.
PROGRESS.md: Milestones 0 to 7 as checkboxes, plus "Current focus", "Last completed", "Next up", and the date of each update.
CONTRACTS.md: endpoints for Orders and Inventory, generated MCP tool names, and the evidence and finding schemas. This is the file that keeps the backend and frontend in sync.
DECISIONS.md: one line each, in the form date, decision, reason.
KNOWN_ISSUES.md: open problems with the exact error text and what you tried.
DEMO_STATE.md: the deterministic counts (28 delayed, 9 tickets, and so on), the exact demo prompt, and which steps you've rehearsed.
